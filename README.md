# im-system 高性能即时通讯服务

## 项目概述
基于 SpringBoot + Netty 自研高性能即时通讯服务端，采用事件驱动模型实现 WebSocket 长连接通信，支撑高并发用户接入与消息实时推送；通过 Redis 实现分布式在线用户状态维护，结合 RabbitMQ 构建异步消息处理链路，实现业务解耦与流量削峰，完整覆盖用户登录、在线管理、消息广播、异常容错等核心场景。

## 技术栈
- 核心框架：SpringBoot、Netty、WebSocket
- 中间件：Redis、RabbitMQ
- 构建工具：Maven

## 核心功能
1. **高并发长连接服务**
   基于 Netty 构建 WebSocket 服务端，通过 Reactor 线程模型实现事件驱动通信，优化心跳检测与空闲连接清理，保障高并发场景下连接稳定性与低延迟传输。

2. **用户会话与状态管理**
   设计用户登录认证机制，客户端首次接入完成身份校验；通过 Redis 维护分布式在线用户状态，实现用户上下线自动感知、会话生命周期管理与状态持久化。

3. **消息广播与异步处理**
   实现全局消息广播功能，支持在线用户实时消息推送；通过 RabbitMQ 对聊天消息进行异步投递与消费，削峰填谷，提升系统吞吐能力与可用性。

4. **服务容错与资源管控**
   完善连接异常捕获、优雅关闭与资源回收机制，防止连接泄漏；通过合理的异常处理策略，避免单用户异常影响整体服务稳定性。

## 项目亮点
- 深入实践 Netty 高性能网络编程，掌握事件驱动模型、Channel 通道管理与协议编解码优化思路。
- 结合 Redis 与 RabbitMQ 构建异步消息架构，理解分布式场景下状态缓存、消息解耦与流量削峰的设计思想。
- 自行设计长连接会话管理模型，完整实现高并发场景下的用户状态维护、消息路由与异常容错，具备后端服务架构设计与落地能力。
